# Sơ đồ kiến trúc khái niệm (Conceptual Architecture)

> Sơ đồ này trình bày **vai trò và trách nhiệm** của từng tầng trong hệ thống,

## Chú thích dùng trong luận văn

| Ký hiệu | Ý nghĩa |
|---------|---------|
| 🟦 **Xanh dương** | Code và thuật toán **đề xuất trong luận văn** (profiler, cost model, planner, orchestrator) |
| 🟩 **Xanh lá** | Code **có sẵn trong framework** ColossalAI, PyTorch, HuggingFace (HybridParallelPlugin, ShardFormer, DDP, GPT2 model) |
| 🟨 **Vàng** | **Dữ liệu đầu vào** do ngườidùng cung cấp hoặc auto-detect từ hệ thống |
| ➡️ Mũi tên | Luồng dữ liệu / điều khiển giữa các khối |
